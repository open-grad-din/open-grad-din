# 報名表格

`build-form.gs` 是建立報名、投票及訂金 Google 表格的 Apps Script。表格的每一題、每個選項、跳頁規則及提交後寄出的「付款指示」電郵，都寫在這個檔案內，任何人都可以拿正式表格和這裏對照。

- 正式表格必須由統籌在**她自己的 Google 帳戶**執行建立（`PROTOTYPE = false`，填入真收款人資料）。觸發器及付款指示電郵都以執行者的帳戶運作，所以開發者不可以執行正式版。
- 執行方法及建立後要人手完成的兩項設定，寫在檔案開頭。
- 表格建立後如要改動，先改這個檔案（經 Pull Request），再公開說明。
- 場地選項及勝出規則必須與網站相同。`check-venues.js` 會在每次部署時對照 `site/venues-params.js` 及 `site/fees-params.js`，不一致就停止部署。
- 方案人形圖截自網站「費用」頁，製作方法見 `tools/form-image/`。
