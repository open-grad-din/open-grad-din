# 投票及報名表格

2026-11-05 籌委會決定投票與交訂金分開，分兩個階段、兩張表格：

1. **第一階段：投票**（`build-vote-form.gs`）。場地揀 3 個（不分先後，每個剔一樣計，最多家庭剔選的勝出），分擔方案三揀一，雜費用途最多揀 2 項。照收預計出席人數及電話（只作預訂座位參考），不收付款資料、不寄電郵。
2. **第二階段：報名及交訂金**，投票結果公布後進行。`build-form.gs` 是之前「報名、投票及訂金一次完成」的表格，留作第二階段的底本；它的投票頁已作廢，第二階段定案時會改寫。現在不要執行。

表格的每一題、每個選項及跳頁規則都寫在 script 內，任何人都可以拿正式表格和這裏對照。

- 正式表格必須由統籌在**她自己的 Google 帳戶**執行建立（`PROTOTYPE = false`）。開發者不可以執行正式版。
- 執行方法及建立後要人手完成的設定，寫在檔案開頭。
- 表格建立後如要改動，先改 script（經 Pull Request），再公開說明。
- 場地選項及勝出規則必須與網站相同。`check-venues.js` 會在每次部署時對照 `build-vote-form.gs` 與 `site/venues-params.js` 及 `site/fees-params.js`，不一致就停止部署。
- 方案人形圖截自網站「費用」頁，製作方法見 `tools/form-image/`。
