# Open Grad Din

學之園凱帆校 K3 畢業晚宴（2027 年 7 月 2 日）的公開名單網頁。

> 目前是**示範版**，網頁上的名單全部是假資料。是否正式使用，由籌委會決定。

## 這個網頁做甚麼

全級家長打開同一條連結，就看到同一份「已確認名單」，不用靠班代轉發。

## 名單怎樣計算

1. 家長經統籌的 Google 表格報名。
2. 統籌核對付款紀錄後，在統籌的 Google 試算表把該家庭標記為「已核實」。
3. 網頁只計算標記為「已核實」的家庭。只報名、未付款的不會計入任何數字。

網頁顯示的數字：

- **已確認畢業生**：已核實的家庭數目（一位畢業生算一個）。
- **出席總人數**：已核實家庭填報的出席人數總和。
- **未核實**：已報名但未核實的數目，只作參考，不計入以上數字。

## 為甚麼可以相信這些資料

- **資料不在開發者手上。** 名單存放在統籌自己的 Google 試算表。這個網頁只「讀」統籌公開發佈的分頁，沒有任何修改資料的功能。
- **資料來源公開。** 網頁底部寫明資料從哪裏讀取，任何人都可以直接打開核對。
- **每次改動有紀錄。** 網頁的程式碼全部公開在這裏。每次改動都要經過審閱才可合併，並永久留下紀錄。網頁底部顯示目前版本的編號，按下去就看到該版本的完整內容。
- **公開分頁只有四欄**：學生名、班別、出席人數、核實狀態。電話、電郵、付款資料等個人資料不會放上網，也不會放進這裏。

## 系統出事怎麼辦

網頁只是「顯示」統籌的試算表。網頁壞了，資料仍然完整地在統籌的 Google 試算表裏，籌備工作照常進行，以統籌的正式通告為準。

## 給管理員：技術資料

- 純靜態網頁（`site/`），經 GitHub Actions 從 `main` 部署到 GitHub Pages。沒有後端、沒有資料庫、沒有密碼或密鑰。
- 資料來源設定在 [`site/config.js`](site/config.js)：`csvUrl` 指向 Google 試算表「發佈到網上」的 CSV 連結。示範版指向 [`site/data/demo.csv`](site/data/demo.csv)。
- Google 發佈的 CSV 約每 5 分鐘更新一次，試算表改動後網頁可能稍遲才反映。
- 公開分頁第一行必須是：`學生名,班別,出席人數,核實狀態`；核實狀態必須是「已核實」三個字才會計算。
- 本地測試：在 `site/` 目錄執行 `python3 -m http.server`，打開 http://localhost:8000 。

### 一次性設定（repo 擁有人做）

1. Settings → Pages → Source 選 **GitHub Actions**。
2. Settings → Branches（或 Rules）為 `main` 加保護：必須經 Pull Request、至少一人批准、禁止 force push、禁止刪除，並剔選「不容許管理員略過」。
